# Google Cloud Digital Leader

La certificazione d'ingresso di Google Cloud. Verifica che sai spiegare **perché** un'organizzazione usa il cloud
e quali prodotti Google Cloud servono per dati, intelligenza artificiale, modernizzazione delle applicazioni,
sicurezza e operazioni. È un esame di concetti, non di configurazione.

| | |
|---|---|
| **Ente** | Google Cloud |
| **Formato** | 50-60 domande a scelta singola o multipla |
| **Durata** | 90 minuti |
| **Punteggio** | superato o non superato; la soglia non è pubblicata |
| **Costo** | 99 USD (più tasse locali) |
| **Validità** | 3 anni |
| **Modalità** | online con sorvegliante oppure in un centro d'esame |
| **Pagina ufficiale** | [cloud.google.com/learn/certification/cloud-digital-leader](https://cloud.google.com/learn/certification/cloud-digital-leader) |

Formato e prezzo verificati il 28 ottobre 2026. Controlla sempre la pagina ufficiale prima di prenotare.

## A chi serve

- In alternativa o in aggiunta alla AWS Cloud Practitioner, se punti ad aziende che usano Google Cloud.
- A chi vuole un primo riconoscimento sul cloud con un esame meno tecnico.

## Quando sostenerla

Dopo la [Fase 4](../../fase-4/index.md), seguendo anche le schede **Google Cloud** delle lezioni. Prima di
prenotare: almeno l'80% negli allenamenti di ogni sezione e tre [esami completi](simulazione.md) superati di fila.

## Piano di studio (4 settimane)

| Settimana | Attività |
|---|---|
| 1 | Sezioni 1 e 6: ripasso 0.6, 4.1, 4.2, 4.3, 4.9. Gerarchia delle risorse, fatturazione, affidabilità |
| 2 | Sezioni 2 e 3: ripasso 4.8. BigQuery, Looker, Pub/Sub, Dataflow, Vertex AI, Gemini |
| 3 | Sezioni 4 e 5: ripasso 4.5, 4.4, 5.6, 5.9. Compute, container, serverless, IAM, sicurezza |
| 4 | Esami completi e ripasso degli errori |
