# Canonical Academy · Linux SysAdmin (Ubuntu)

Il programma di certificazione di Canonical, l'azienda che sviluppa Ubuntu. La qualifica **Linux SysAdmin** si
ottiene superando quattro esami, che si possono sostenere uno alla volta e in qualunque ordine.

| Esame | Durata |
|---|---|
| Using Linux Terminal | 75 minuti |
| Using Ubuntu Desktop | 90 minuti |
| Using Ubuntu Server | 90 minuti |
| Using DevOps Principles | 90-120 minuti (stima indicata da Canonical) |

| | |
|---|---|
| **Formato** | ibrido: domande a scelta, scenari e prove pratiche su un sistema virtuale |
| **Ambiente** | desktop Ubuntu remoto nel browser (Guacamole); nodo iniziale Ubuntu 24.04 LTS, altri nodi Ubuntu Server 22.04 LTS; pagine man e documentazione Ubuntu disponibili |
| **Sorveglianza** | Proctor360, con webcam, microfono, condivisione dello schermo e un solo monitor |
| **Browser** | basato su Chromium (Firefox non è supportato) |
| **Costo e regole sui nuovi tentativi** | vedi la pagina ufficiale |
| **Pagina ufficiale** | [canonical.com/academy](https://canonical.com/academy) · [guida agli esami](https://canonical.com/academy/exam-guide) · [contenuti degli esami](https://canonical.com/academy/exam-content) |

Dati verificati il 28 ottobre 2026.

!!! warning "Una valutazione onesta"
    Canonical Academy è un programma **recente**: oggi è molto meno conosciuto dai selezionatori rispetto a LFCS e
    RHCSA, e non sempre compare negli annunci di lavoro. Ha senso se punti ad aziende che usano Ubuntu, se vuoi
    certificare le competenze un passo alla volta o se il costo degli altri esami è un ostacolo. Se devi
    sceglierne una sola per il curriculum, la [LFCS](../lfcs/index.md) o la [RHCSA](../rhcsa/index.md) oggi pesano
    di più.

## Quando sostenerla

- **Using Linux Terminal** e **Using Ubuntu Server**: dopo la [Fase 1](../../fase-1/index.md) sul percorso
  Debian/Ubuntu.
- **Using Ubuntu Desktop**: dopo la [Fase 1](../../fase-1/index.md), con un po' di pratica su Ubuntu Desktop (driver, aggiornamenti di
  versione, snap).
- **Using DevOps Principles**: dopo la [Fase 3](../../fase-3/index.md) e la lezione [6.10](../../fase-6/10-ansible.md).

## Requisiti tecnici

Prima dell'esame installa l'estensione di Proctor360 per Chrome ed esegui il controllo del sistema. Servono almeno
4 GB di RAM e una connessione stabile (Canonical consiglia 10 Mbit/s in entrambe le direzioni); evita VPN, proxy e
firewall aziendali. Nell'ambiente remoto alcune scorciatoie del browser non funzionano come in un terminale
(`Ctrl+W` chiude la scheda): abituati a usare le alternative.
