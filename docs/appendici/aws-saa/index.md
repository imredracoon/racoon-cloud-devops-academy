# AWS Certified Solutions Architect – Associate (SAA-C03)

La certificazione AWS più richiesta negli annunci per ruoli cloud e DevOps junior. Verifica che sai **progettare**
architetture sicure, resilienti, performanti ed economiche a partire da requisiti reali, scegliendo tra più servizi
quello giusto per ogni vincolo.

| | |
|---|---|
| **Ente** | Amazon Web Services |
| **Codice** | SAA-C03 |
| **Formato** | 65 domande a scelta singola o multipla (50 valutate, 15 non valutate) |
| **Durata** | 130 minuti |
| **Punteggio** | scala da 100 a 1.000, soglia **720** |
| **Costo** | 150 USD (più tasse locali) |
| **Validità** | 3 anni |
| **Modalità** | centro d'esame Pearson VUE oppure online con sorvegliante |
| **Pagina ufficiale** | [aws.amazon.com/certification/certified-solutions-architect-associate](https://aws.amazon.com/certification/certified-solutions-architect-associate/) |

Formato e prezzo verificati il 28 ottobre 2026. Controlla sempre la pagina ufficiale prima di prenotare.

!!! tip "Sconto sul secondo esame"
    Chi supera un esame AWS riceve di norma un buono sconto per il successivo, visibile nel proprio account di
    certificazione. Se hai superato la Cloud Practitioner, controlla prima di pagare.

## A chi serve

A chiunque punti a un ruolo cloud, DevOps o platform engineer. È spesso la prima certificazione che i selezionatori
cercano insieme a Terraform e Kubernetes.

## Quando sostenerla

Dopo la [Fase 5](../../fase-5/index.md) e il suo progetto. Prima di prenotare devi:

- aver costruito l'applicazione a tre livelli del Progetto 5 (rete, bilanciamento, database, monitoraggio);
- superare con almeno l'80% gli allenamenti di ogni dominio e tre [esami completi](simulazione.md) di fila.

## Piano di studio (8 settimane, 8-10 ore a settimana)

| Settimane | Attività |
|---|---|
| 1-2 | *Design Secure Architectures*: ripasso [4.4](../../fase-4/04-iam.md), [5.1](../../fase-5/01-vpc.md), [5.6](../../fase-5/06-sicurezza.md). IAM e policy, VPC, cifratura, Organizations e SCP |
| 3-4 | *Design Resilient Architectures*: ripasso [5.2](../../fase-5/02-ha-scaling.md), [5.4](../../fase-5/04-database.md), [5.5](../../fase-5/05-messaggistica.md). Multi-AZ, Auto Scaling, disaccoppiamento, disaster recovery |
| 5 | *Design High-Performing Architectures*: ripasso [5.3](../../fase-5/03-storage.md), [5.7](../../fase-5/07-dns-cdn.md), [5.9](../../fase-5/09-container-serverless.md). Scelta di storage, database, cache, CDN |
| 6 | *Design Cost-Optimized Architectures*: ripasso [4.9](../../fase-4/09-costi.md), [5.10](../../fase-5/10-well-architected.md). Modelli di prezzo, classi di storage, costi di rete |
| 7-8 | Esami completi, ripasso degli errori, approfondimento dei servizi dove sbagli di più |
